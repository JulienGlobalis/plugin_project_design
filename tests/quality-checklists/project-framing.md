# Project Framing Checklist

## Current Contract

- [ ] Context and objectives are supported by source evidence.
- [ ] Scope and exclusions remain distinct from unapproved ideas.
- [ ] Stakeholders and actors are not invented or silently merged.
- [ ] Constraints, risks, assumptions, decisions, and open questions are
      distinguishable.
- [ ] Missing ownership, evidence, or decision authority remains visible.
- [ ] The output does not define functional requirements, technical
      architecture, or backlog items.
- [ ] The skill remains independently callable and Spec Kit independent.
