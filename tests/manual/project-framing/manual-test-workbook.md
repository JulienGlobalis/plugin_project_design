# Project Framing Manual Test Workbook

Use this workbook during or immediately after one real `project-framing`
test. Do not commit confidential project information or a completed client
workbook to the repository.

Allowed results:

- `PASS`
- `PASS WITH RESERVATIONS`
- `FAIL`

## Test Procedure

1. Provide the available project sources or Project View.
2. Invoke `project-framing` and state the requested language and purpose when
   they are not evident.
3. Answer only questions that are useful for this test; defer the others.
4. Review the framing against the sources and the checklist below.
5. Record concrete issues, examples, and improvement requests.
