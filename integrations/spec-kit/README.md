# GitHub Spec Kit Integration

The installable
[Spec Kit boundary](../../plugins/project-design/shared/spec-kit-boundary.md)
defines the normative rule: `project-design` remains fully usable without
GitHub Spec Kit.

This development-only integration directory contains:

- [compatibility notes](compatibility.md);
- [future artefact mappings](mapping.md).

Automatic command execution, installation, template modification,
synchronization, and runtime artefact conversion are not implemented.
